# awc-accordion-item

## Properties

| Property   | Attribute  | Type      | Default | Description                    |
|------------|------------|-----------|---------|--------------------------------|
| `active`   | `active`   | `boolean` | "false" | Активность элемента аккордеона |
| `disabled` | `disabled` | `boolean` | "false" | Отключение элемента аккордеона |
| `title`    | `title`    | `string`  | ""      | Заголовок элемента аккордеона  |

## Events

| Event                  | Description                                      |
|------------------------|--------------------------------------------------|
| `awc-accordion-toggle` | Событие активности элемента. Срабатывает при переключении активности. |
