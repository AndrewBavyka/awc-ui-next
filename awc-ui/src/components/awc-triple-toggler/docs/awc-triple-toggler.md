# awc-triple-toggler

`awc-triple-toggler` - Компонент тройного переключателя.

Этот компонент представляет собой тройной переключатель с возможностью выбора одного из трех состояний.

## Properties

| Property | Attribute | Type                             | Default | Description              |
|----------|-----------|----------------------------------|---------|--------------------------|
| `state`  | `state`   | `"first" \| "second" \| "third"` | "first" | Состояние переключателя. |

## Events

| Event                       | Description                                      |
|-----------------------------|--------------------------------------------------|
| `awc-triple-toggler-change` | Событие, которое срабатывает при изменении состояния переключателя. |
