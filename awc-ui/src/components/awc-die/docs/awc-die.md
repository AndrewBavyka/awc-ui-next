# awc-die

`awc-die` - Компонент для отображения редактируемого или только для чтения текстового поля.

## Properties

| Property      | Attribute     | Type      | Default                    | Description                                      |
|---------------|---------------|-----------|----------------------------|--------------------------------------------------|
| `color`       | `color`       | `string`  | "'--colors-light-primary'" | Цвет компонента, может быть установлен как цвет или переменная CSS. |
| `editing`     | `editing`     | `boolean` | "false"                    | Флаг, указывающий, находится ли компонент в режиме редактирования. |
| `placeholder` | `placeholder` | `string`  | "''"                       | Заглушка (Placeholder).                          |
| `text`        | `text`        | `string`  | "''"                       | Текст заголовка комопнента                       |

## Events

| Event            | Description                                      |
|------------------|--------------------------------------------------|
| `awc-die-blur`   | Событие потери фокуса. Диспетчер событий возвращает текущий текст. |
| `awc-die-change` | Событие изменения состояния. Диспетчер событий возвращает новый текст. |
| `awc-die-focus`  | Событие фокусировки. Диспетчер событий возвращает текущий текст. |

## CSS Custom Properties

| Property          | Description                                      |
|-------------------|--------------------------------------------------|
| `--awc-die-color` | В данную переменную устанаваливаеся как цвет так и переменная CSS из атрибута color. |
