# awc-icon

Элемент для отображения иконок.

## Properties

| Property    | Attribute    | Type     | Default | Description                              |
|-------------|--------------|----------|---------|------------------------------------------|
| `iconScale` | `icon-scale` | `string` | ""      | Изменение размеров иконки                |
| `name`      | `name`       | `string` | ""      | Имя или идентификатор конкретной иконки. |
| `size`      | `size`       | `string` | "16"    | Указываеся размер иконки                 |
| `type`      | `type`       | `string` | "icon"  | Элемент для отображения иконок.          |
