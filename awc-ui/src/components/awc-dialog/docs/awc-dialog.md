# awc-dialog


Небольшое окно, используемое для отображения информации.

## Properties

| Property      | Attribute     | Type      | Default | Description                 |
|---------------|---------------|-----------|---------|-----------------------------|
| `description` | `description` | `string`  | ""      | Описание окна               |
| `heading`     | `heading`     | `string`  | ""      | Заголовок окна              |
| `opened`      | `opened`      | `boolean` | "false" | Флаг открытия/закрытия окна |
| `variant`     | `variant`     | `String`  | "info"  | Вариант отображения окна    |

## Methods

| Method  | Type       | Description               |
|---------|------------|---------------------------|
| `close` | `(): void` | Закрытие диалогового окна |
| `open`  | `(): void` | Открытие диалогового окна |

## Events

| Event              | Description                                      |
|--------------------|--------------------------------------------------|
| `awc-dialog-close` | Событие, возникающее при закрытии диалогового окна. |
| `awc-dialog-open`  | Событие, возникающее при открытии диалогового окна. |
