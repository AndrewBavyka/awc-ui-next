# awc-split-button

Комбинированная кнопка для выполнения либо одного действия, либо нескольких.

## Properties

| Property   | Attribute   | Type      | Default | Description                             |
|------------|-------------|-----------|---------|-----------------------------------------|
| `menuOpen` | `menu-open` | `boolean` | "false" | Определяет, открыто ли выпадающее меню. |

## Methods

| Method             | Type       | Description                |
|--------------------|------------|----------------------------|
| `splitButtonClose` | `(): void` | Закрывает выпадающее меню. |
| `splitButtonOpen`  | `(): void` | Открывает выпадающее меню. |

## Events

| Event                    | Description                                      |
|--------------------------|--------------------------------------------------|
| `awc-split-button-close` | Событие, возникающее при закрытии выпадающего списка. |
| `awc-split-button-open`  | Событие, возникающее при открытии выпадающего списка. |

## Slots

| Name               | Description                                 |
|--------------------|---------------------------------------------|
|                    | Общий слот для контента выпадающего списка. |
| `awc-split-button` | Слот для контента кнопки.                   |
