# awc-icon-button

## Properties

| Property   | Attribute  | Type      | Default  | Description                                      |
|------------|------------|-----------|----------|--------------------------------------------------|
| `disabled` | `disabled` | `Boolean` | "false"  | Флаг, отключающий кнопку.                        |
| `href`     | `href`     | `String`  | ""       | Задает адрес документа, на который следует перейти. |
| `name`     | `name`     | `String`  | ""       | Имя кнопки.                                      |
| `size`     | `size`     | `String`  | "24"     | Размер кнопки (Вложенные иконки меняют размер в том числе). |
| `target`   | `target`   | `String`  | "_self"  | Тип перехода по ссылке.                          |
| `type`     | `type`     | `String`  | "submit" | Тип кнопки.                                      |
| `value`    | `value`    | `String`  | ""       | Значение кнопки.                                 |
