# awc-pagination

## Properties

| Property          | Attribute           | Type      | Default | Description                                      |
|-------------------|---------------------|-----------|---------|--------------------------------------------------|
| `activePage`      | `active-page`       | `number`  | "1"     | Индекс активной в данный момент страницы.        |
| `first`           | `first`             | `boolean` | "false" | Кнопка первой страницы.                          |
| `itemsPerPage`    | `items-per-page`    | `number`  | "1"     | Общее количество элементов, которые должны отображаться на странице. |
| `last`            | `last`              | `boolean` | "false" | Кнопка последней страницы.                       |
| `totalItemsCount` | `total-items-count` | `number`  | "1"     | Общее количество элементов.                      |
