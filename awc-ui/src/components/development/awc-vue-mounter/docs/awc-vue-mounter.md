# awc-vue-mounter


Этот компонент позволяет динамически монтировать компоненты Vue, используя либо прямой конструктор (construct)
или метод замыкания (closure) для инициализации экземпляра Vue.

## Properties

| Property  | Attribute | Type             | Default     | Description                                      |
|-----------|-----------|------------------|-------------|--------------------------------------------------|
| `name`    | `name`    | `string`         | ""          | Имя конструктора компонента Vue. Это может быть простая строка или путь к вложенному объекту. |
| `options` | `options` | `object`         | {}          | Параметры для передачи в качестве данных экземпляру Vue. |
| `type`    | `type`    | `VueControlType` | "construct" | Тип используемой инициализации: construct или closure. |
