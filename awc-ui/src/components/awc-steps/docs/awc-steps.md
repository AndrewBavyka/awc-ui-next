# awc-steps

Компонент выполняемых шагов.

## Properties

| Property | Attribute | Type       | Default     | Description                                      |
|----------|-----------|------------|-------------|--------------------------------------------------|
| `id`     | `id`      | `string`   | "stepper-1" | Уникальный идентификатор степпера.               |
| `report` | `report`  | `string[]` | "string[]"  | Список названий шагов.                           |
| `status` | `status`  | `number`   | "1"         | Статус шага, предназначен для обновления текущего шага. |
