# Обзор

Этот репозиторий представляет собой монорепозиторий, содержащий две основные части:
- `awc-ui`: набор веб-компонентов, реализованных с использованием Lit и TypeScript.
- `awc-book`: документационный сайт на Vue для демонстрации и тестирования компонентов.

---

### 📁 Структура проекта

```
awc-monorepo/
├── awc-ui/                # Библиотека веб-компонентов (Lit + TypeScript)
│   ├── src/                # Исходный код
│   ├── package.json        # Конфигурация сборки и линтинга
│   └── dist/               # Собранные файлы
├── awc-book/              # Документационный сайт (Vue 3 + TypeScript)
│   ├── src/                # Исходники Vue-приложения
│   ├── public/             # Статические файлы
│   └── package.json        # Зависимости и скрипты
├── package.json           # Корневая конфигурация рабочих пространств
└── README.md              # Этот файл
```

---

### 🔧 Установка и настройка

Чтобы установить зависимости и запустить оба проекта:

```bash
npm run install:all
```

Эта команда:
1. Установит зависимости в `awc-ui`.
2. Установит зависимости в `awc-book`.

---

### 🚀 Запуск проектов

#### Запуск `awc-ui` в режиме разработки

```bash
npm run dev:ui
```

Запускает сервер разработки Vite для библиотеки компонентов.

#### Запуск `awc-book` в режиме разработки

```bash
npm run dev:book
```

Запускает документационный сайт с помощью Vite.

---

### 🏗️ Сборка проектов

#### Сборка `awc-ui`

```bash
npm run build:ui
```

Собирает библиотеку в папку `dist`.

#### Сборка `awc-book`

```bash
npm run build:book
```

Готовит оптимизированную версию сайта для продакшена.

---

### ✅ Линтинг и форматирование

В `awc-ui` используется **ESLint** и **Prettier** для проверки и форматирования кода.

Проверка и автоматическое исправление ошибок:

```bash
npm run lint
npm run format
```

---

### 📦 Рабочие пространства

Репозиторий организован как монорепо с использованием npm workspaces. В корне указано:

```json
"workspaces": ["awc-book", "awc-ui"]
```

Это позволяет совместно использовать типы и утилиты между проектами без публикации в NPM.

Проект `awc-book` ссылается на `awc-ui` через локальную зависимость:

```json
"dependencies": {
  "awc-ui": "file:../awc-ui"
}
```
